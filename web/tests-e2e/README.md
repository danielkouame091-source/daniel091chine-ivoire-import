# Tests E2E — Playwright

## Prérequis

1. Backend FastAPI en marche sur `http://localhost:8000`
2. Frontend Next.js en marche sur `http://localhost:3000`
   (ou laisser Playwright le démarrer via `webServer` dans `playwright.config.ts`)
3. Base PostgreSQL + Redis disponibles
4. Playwright installé : `npm run e2e:install`
